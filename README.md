# International Diamond Verified Lab

A responsive fitness and healthy Diamond  web app built with **Vite**, **React**, and **Tailwind CSS**, inspired by International Diamond Verified Lab sleek aesthetic and engaging UX.

---

---

## 🚀 Tech Stack

- **React** – Component-driven UI
- **Tailwind CSS** – Utility-first styling
- **Heroicons + Headless UI** – Smooth, accessible UI components

## 📦 Features

- 🔥 Hero section with background video
- 🌙 Dark mode support
- 🧩 Reusable card layouts for services
- 📱 Fully responsive navigation menu
- 🎯 Custom Tailwind-based components

## 📂 Project Structure

```
src/
├── assets/         # Images, video
├── components/     # Header, HeroSection, Cards
├── pages/          # Homepage & more

```
